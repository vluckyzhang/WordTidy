# WordTidy v0.12

WordTidy v0.12 聚焦多文件队列排版、发布信息完善和低门槛本地启动。

- 上传控件仅允许选择 Word、Markdown 和 TXT 文件。
- 支持一次选择或拖拽多个符合要求的文件。
- 支持排版队列按顺序逐个处理文件。
- 支持从排版队列中删除已选择文件。
- 支持为每个排版成功的文件生成独立下载结果。
- 顶部标题加入项目 slogan，左侧信息区补充“关于”一句话介绍。
- 联系作者独立成行，显式显示邮箱，并可一键打开邮件客户端发送邮件。
- 功能模式文案更新为“标准模式 / AI模式”。
- DeepSeek API 连接状态仅在 AI模式 下显示，并显示为 DeepSeek 专属状态。
- 提供 Windows 和 macOS 程序包，运行可执行文件后会启动本地服务并自动打开浏览器使用。
- README 保留参与贡献、许可证和联系交流信息，仅移除发布第一版说明。

程序包说明：

- Windows：解压 `WordTidy_v0.12_Windows_executable.zip` 后运行 `WordTidy.exe`。
- macOS：解压 `WordTidy_v0.12_macOS_executable.zip` 后运行 `WordTidy`。
- `.doc` 转 `.docx`、`.docx` 转 PDF 仍需要本机安装 LibreOffice。
