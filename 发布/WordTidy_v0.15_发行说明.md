# WordTidy v0.15

WordTidy v0.15 聚焦排版规则资源命名、README 架构图和发布包同步。

- 将项目中的 `示例/` 文件夹更名为 `排版规则/`。
- 将 `论文排版预设.json` 更名为 `排版预设.json`。
- 同步 README、目录结构说明和版本展示。
- README 架构部分使用项目内架构图资源。
- 联系作者邮箱与复制按钮同排展示，并修正联系邮箱。
- 前端、后端、构建脚本和发布说明统一到 `0.15`。

程序包说明：

- Windows：解压 `WordTidy_v0.15_Windows_executable.zip` 后运行 `WordTidy.exe`。
- macOS：解压 `WordTidy_v0.15_macOS_executable.zip` 后运行 `WordTidy`。
- `.doc` 转 `.docx`、`.docx` 转 PDF 仍需要本机安装 LibreOffice。
