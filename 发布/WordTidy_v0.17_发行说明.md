# WordTidy v0.17 发行说明

发布日期：2026-06-22

WordTidy v0.17 聚焦后端连接状态可视化、排版前健康检查和错误提示优化，避免后端未启动时只显示笼统的 `请求失败：500`。

## 更新内容

- 顶部右上角新增后端连接状态标识：
  - 后端检测中
  - 后端已连接
  - 后端未连接
- 新增后端连接状态手动刷新按钮。
- 前端启动后自动检测 `/api/health`，并定时静默刷新连接状态。
- 排版提交前先执行后端健康检查，后端不可用时不再继续提交 `/api/format`。
- 对 Vite 代理 500、连接拒绝、网络失败等情况统一给出“后端未连接”的明确提示。
- 后端未连接时禁用排版提交，减少无效请求。
- AI 模式下仍只显示 DeepSeek API 状态，标准模式不显示 DeepSeek 状态。
- 修复 DeepSeek 空 API key 测试时出现不友好 body parsing 错误的问题。
- `.learnings/` 本地学习日志加入 `.gitignore`，避免误提交或误打包。
- 统一前端、后端、构建脚本和文档版本号为 `0.17`。

## 验证

- 前端生产构建通过。
- 后端单元测试通过。
- 后端代码编译检查通过。
- 已验证后端未启动时顶部显示“后端未连接”。
- 已验证后端启动后顶部显示“后端已连接”。
- 已验证 `.md` 文档通过 `/api/format` 成功生成 DOCX。
